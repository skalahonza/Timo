# Sensor, Cannula & Cartridge Tracker

This app helps users monitor the age of their sensors and cannulas, displaying real-time updates on their duration of use. The app shows the current sensor and cannula counts, as well as the elapsed time since the last replacement. It also tracks available insulin pump cartridges by count. Users can easily reset or edit the timer for timed items and adjust counts, making it convenient for managing replacement schedules.

## Features
- Real-time tracking of sensor and cannula usage time.
- Cartridge count tracking (without time tracking).
- Easy-to-read interface showing days, hours, minutes, and seconds.
- Quick reset and edit options for sensors, cannulas, and cartridges.
- Color-coded age indicators for clear status updates.

Ideal for users needing precise tracking for medical equipment or similar timed items.
